# 013. Окно «Журнал будет стёрт»: стрелки влево/вправо уводят фокус на «Новая игра» под окном

- **Серьёзность:** minor (клавиатура и геймпад)
- **Кому:** ui-dev (`game/main.gd`, `_show_confirm_new_game`)
- **Статус:** открыт

## Шаги
1. Есть сохранение журнала. Главное меню → «Новая игра» → окно подтверждения, фокус на «Отмена».
2. Нажать ←.
3. Нажать Enter.

## Ожидалось
← переводит фокус на «Стереть и начать»; фокус не покидает окно (как уже сделано для ↑/↓).

## Получилось
- ← с «Отмена» — фокус на кнопке меню «Новая игра» под окном (её не видно). Ещё ← — «Стереть и начать». → с «Стереть и начать» — снова «Новая игра», ещё → — «Отмена».
- Enter, когда фокус на скрытой «Новая игра», открывает второе окно подтверждения поверх первого (фон темнеет вдвое); ссылка на первое окно в `_confirm` теряется.
- Фокус ↑/↓ закрыт через `focus_neighbor_top/bottom`, а `focus_neighbor_left/right` (и `focus_next/previous` для Tab) не заданы.

Проверено скриптом QA через `Input.parse_input_event` на `game/main.tscn` в окне.
